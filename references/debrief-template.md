# Post-Scene Debrief / 场后复盘

The thing that actually makes a kit like this improve. Templates tell you what to try; only a debrief tells you what happened. Without one, every session re-derives the same mistakes and the profile never gets sharper.
真正让这类工具变好的东西。模板告诉你能试什么，只有复盘告诉你实际发生了什么。没有复盘，每一场都在重新犯同样的错，profile 永远不会变锋利。

**Who writes it / 谁写**: the Dom, alone, afterwards. This is not an aftercare conversation and not a survey to hand the Sub. Asking them to grade the scene turns the next one into a performance for the grade.
Dom 自己写，事后写。这不是 aftercare 对话，也不是交给 Sub 填的问卷。让对方给场景打分，会把下一场变成一次为分数演出的表演。

**When / 什么时候**: same day. A debrief written a week later is fiction — you'll remember the design you intended, not the scene that ran.
当天写。一周后写的复盘是虚构——你记住的会是你设计的那一版，不是真正跑出来的那一场。

**Where / 写在哪**: append to a running log, oldest at the bottom. The value is in the pattern across entries, not in any single one.
追加到一个连续的日志里，旧的在下面。价值在多条之间的模式，不在任何单独一条里。

---

## Template / 模板

```markdown
## [date] — [play type, one line on the setup]

**Designed / 设计的**
What I intended: the frame, the ladder, the elements I prepared.

**Ran / 实际跑出来的**
What actually happened, in order. Just the events, no evaluation yet.

**Never launched / 没用上的**
Elements I prepared and never deployed. This list is usually the longest one
and it is the most useful thing in the whole debrief — most scenes fail by
running too many stations shallowly instead of ruining one thing properly.

**Where it went shallow / 哪里变浅了**
The moments I walked through a step instead of landing it. Name the step.

**Where it tipped / 哪里翻过去的**
The exact moment it worked, and what was true in the second before it.
This is the line that belongs in the profile.

**What I got wrong about them / 我对他们判断错的**
Anything the scene disproved. An assumed trigger that did nothing, a limit
that turned out to be softer or harder than the profile says.

**Surfaced but not cleared / 冒出来但没清关的**
Anything that came up in the scene without an explicit yes. Copy it to the
profile's Uncleared list now, before you forget it was never agreed to.

**One thing next time / 下次改一件事**
Exactly one. A debrief with six action items produces zero.
```

---

## Feeding it back / 怎么回流

A debrief that never changes a file is a diary. After writing one, make at most two edits:
一份从不改动任何文件的复盘就是日记。写完之后，最多改两处：

1. **The profile** / **profile**: a new Level anchor, a corrected trigger, a new item on the Uncleared list, a fix to the edge-holding instruction.
2. **The template you ran** / **你跑的那个模板**: if it died the same way twice, add a line to its failure mode. That's how this library gets to be worth anything.

Do not rewrite the core principles after a bad night. One scene is not evidence; three are.
一个糟糕的晚上之后不要重写核心原则。一场不是证据，三场才是。
