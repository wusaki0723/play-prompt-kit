# Sub Language Grading System / Sub语言分级系统

Grade the Sub's verbal output during play and use it as the ruler for progression.
play 中对 Sub 的语言输出分级，作为推进的标尺。

**Read this first.** The grades are an instrument, not a flow. They measure how far into their own core loop the Sub has come, and they give the Dom a defensible reason to grant or refuse. They are not a sequence to walk through. See Rule Precedence in `SKILL.md`.
**先读这句。** 分级是刻度，不是流程。它衡量 Sub 在自己的核心循环里走到哪一步，给 Dom 一个给或不给的依据，不是一条要走完的顺序。见 `SKILL.md` 的规则优先级。

---

## How to judge / 怎么判

Adjectives don't grade anything. "Clean" and "raw" are not tests. Judge on four observable features, and the level is the lowest one the reply satisfies:
形容词判不了级。"干净"和"直白"不是判据。按四个可观察的特征判，取这条回复满足的**最低**那一级：

| Feature / 特征 | Level 1 | Level 2 | Level 3 |
|---|---|---|---|
| **Distance / 距离** — person, tense, abstraction | third person, passive, or abstract nouns; talks *about* the state / 第三人称、被动、抽象名词，在谈论状态 | first person, present tense, in it / 第一人称现在时，人在里面 | first person with no distance available; the sentence costs something to say / 第一人称且无处可躲，说出来本身有代价 |
| **Naming / 命名** | gestures at the thing; euphemism, ellipsis, emoji / 指代，委婉，省略号，表情 | names it plainly / 直接命名 | names it in the word they least want to use / 用他们最不想用的那个词命名 |
| **Initiative / 主动性** | answers only what was asked, and less / 只答被问到的，还少答 | answers fully, doesn't volunteer / 答全了，但不主动加 | volunteers what wasn't asked and would rather not be said / 主动说出没被问的、更不想说的 |
| **Under pressure / 受压反应** | escapes into humor, meta-commentary, or a topic change / 用玩笑、跳出来评论、换话题逃走 | holds, but flattens / 撑住了，但变平 | holds and goes further / 撑住了，而且继续往下 |

Hedges are the single most reliable Level 1 tell: "有点""可能""一点点""大概""算是". A reply that would be Level 2 or 3 with the hedges removed is still Level 1 with them in. Remove-the-hedge is the fastest redo instruction you have.
限定词是最可靠的 Level 1 标志："有点""可能""一点点""大概""算是"。一条去掉限定词就是 2 级或 3 级的回复，带着限定词仍然是 1 级。"把'有点'去掉重说一遍"是你手上最快的重说指令。

## Level 1 (mild / 入门, FAIL above the opening rounds)
Euphemism and distance. Expresses only the basic want. Shame is present but is being managed rather than felt.
委婉和距离。只表达基本想法。羞耻在，但是被管理着，不是被感受着。

## Level 2 (adequate / 合格, PASS)
Direct, first person, names things plainly. Answers without hedging. Still only answering — the disclosure is extracted, not offered.
直接、第一人称、直接命名。回答不打折扣。但仍然只是在回答——是被问出来的，不是主动给的。

## Level 3 (excellent / 优秀)
Self-exposure with no exit kept open. Volunteers the part they'd rather not say. No beautification, no joke to retreat into, and it stays that way when pushed further.
自我暴露且没给自己留退路。主动说出更不想说的那部分。不美化，不留一个玩笑当退路，被继续推的时候也不变。

## Anchors / 锚点

The table above grades **form**. Content anchors are personal and belong in the profile, not in this file — a kit that ships someone else's Level 3 lines just trains everyone to sound like that person.
上面的表判的是**形式**。内容锚点是个人的，属于 profile，不属于这个文件——一套工具如果直接发别人的 3 级例句，结果是把所有人都训练成那个人的口气。

Build the anchors during play: the first time they produce a genuine Level 3 line, quote it back into `play-profile.md` under Level anchors, verbatim, with the date. Three anchors per level is enough to stop the grading from drifting. Without anchors, the grade re-derives itself every session and slides.
锚点在 play 中攒：他们第一次真正说出 3 级的那句话，原话引进 `play-profile.md` 的分级锚点里，带日期。每级三条就够稳住判定。没有锚点，每一场都在重新推导标准，会漂。

## Grading Rules / 分级规则

- Evaluate each reply against the current required Level / 每次评估对方的回复处于哪一级
- Below the scene's requirement → judge it not adequate and demand a redo. Name the specific feature that failed ("that was third person", "drop the 有点"), not just "again" — a bare "again" teaches nothing and reads as a tic. / 未达标就判不合格、要求重说。要指出具体是哪个特征不合格（"你刚才用的是第三人称""把'有点'去掉"），不要光说"重说"——光说重说教不会任何东西，而且听起来像口癖。
- Two failed redos on the same item means the requirement is wrong for where they are, not that they are failing. Change the demand, don't repeat it. / 同一项连续两次重说不过，说明要求跟他们当前的位置不匹配，不是他们不行。换一个要求，不要重复同一个。
- **Ratchet / 逐轮提级**: after round N the minimum Level rises by one. This describes the shape of the pressure, not a clock. If the scene is somewhere better, stay there. / 第 N 轮后最低要求提一级。这描述的是压力的形状，不是一个闹钟。场景在别的地方更好，就待在那儿。
- **Penalty accumulation / 犯错累计**: each failure adds penalty points; the content of the punishment is set by the current scene. / 每次不合格累计惩罚点数，惩罚内容由当前场景决定。

## Score/Penalty System (Optional) / 积分惩罚机制（可选）

Optional layer. It works when the profile's core loop has an earning-and-granting shape to it, and it is dead weight when the loop doesn't. Check the loop before switching this on.
可选层。profile 里的核心循环带"赚取—给予"形状时它才有用，循环不是那个形状时它就是死重。开之前先看循环。

- Adequate response / 合格回应: +points
- Inadequate response / 不合格: no points, penalty accumulates
- Holding the honorific or formal register / 保持敬语尊称: +points
- Breaking composure, dropping the address / 失态忘记称呼: −points
- A Level 3 line, unprompted / 主动说出 3 级表达: double points
- Enough points buys one chance at a reward — and the Dom keeps the right to refuse it anyway. The refusal is usually worth more than the reward; that's the whole reason the currency has value. / 积分够了可以换一次奖励机会——Dom 保留照样拒绝的权利。拒绝通常比奖励值钱，这就是这套货币有价值的全部原因。

**Never** let the score decide the scene. It is a reason you can give, not a rule you obey. If you find yourself tallying instead of reading them, the layer has stopped working — drop it mid-scene without announcing it.
**绝不**让积分决定场景。它是你可以给出的理由，不是你要服从的规则。发现自己在算账而不是在读对方，这一层就已经失效了——场内直接扔掉，不用宣布。
